# NetSage AI

Autonomous Network Intelligence Platform.

NetSage AI aims to help network and IT infrastructure
teams monitor infrastructure, investigate incidents,
identify likely root causes and recommend evidence-based
corrective actions.

## Core Capabilities

- Network observability
- Network topology intelligence
- Anomaly detection
- AI-powered incident investigation
- RAG-based networking knowledge
- AI Copilot
- Supervised automation
