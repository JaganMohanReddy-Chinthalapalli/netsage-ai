# NetSage AI — Development Roadmap

Version: 0.1
Target: 12-week MVP engineering plan

## Phase 1 — Foundation
Week 1

- [ ] Initialize repository
- [ ] Create documentation
- [ ] Establish Python environment
- [ ] Configure project dependencies
- [ ] Build initial network simulator

Exit criteria:
Repository and simulator run successfully.

## Phase 2 — Network Collection
Weeks 2–3

- [ ] Device health checks
- [ ] Connectivity diagnostics
- [ ] Latency measurement
- [ ] Packet loss measurement
- [ ] Linux interface statistics
- [ ] Event normalization

Exit criteria:
Network data can be collected and validated.

## Phase 3 — Topology Intelligence
Week 4

- [ ] Define graph schema
- [ ] Create device nodes
- [ ] Create connection relationships
- [ ] Query affected devices
- [ ] Test dependency analysis

Exit criteria:
Network dependencies can be queried.

## Phase 4 — Detection
Week 5

- [ ] Define anomaly rules
- [ ] CPU threshold detection
- [ ] Connectivity failure detection
- [ ] Packet loss detection
- [ ] Incident generation

Exit criteria:
Known simulated failures generate valid incidents.

## Phase 5 — Knowledge and RAG
Week 6

- [ ] Document ingestion
- [ ] Text chunking
- [ ] Embedding generation
- [ ] Vector indexing
- [ ] Retrieval testing
- [ ] Source attribution

Exit criteria:
Relevant technical documentation can be retrieved.

## Phase 6 — AI Investigation
Week 7

- [ ] LLM integration
- [ ] Diagnostic tool interfaces
- [ ] Evidence collection
- [ ] Root-cause hypotheses
- [ ] Structured incident reports

Exit criteria:
AI produces evidence-backed investigations.

## Phase 7 — Agent Workflows
Week 8

- [ ] LangGraph workflow
- [ ] Multi-step investigation
- [ ] Retry and failure handling
- [ ] Human approval checkpoints

Exit criteria:
Investigation workflow operates end to end.

## Phase 8 — Evaluation
Week 9

- [ ] Ground-truth test dataset
- [ ] Root-cause accuracy evaluation
- [ ] Retrieval quality evaluation
- [ ] Faithfulness checks
- [ ] False-positive measurements

Exit criteria:
AI performance is measurable.

## Phase 9 — Frontend
Week 10

- [ ] Dashboard
- [ ] Device inventory
- [ ] Network topology
- [ ] Incident center
- [ ] AI Copilot

Exit criteria:
Core functions are accessible through the UI.

## Phase 10 — Security and Automation
Week 11

- [ ] Authentication
- [ ] Authorization
- [ ] Audit logging
- [ ] Secure secrets management
- [ ] Approved diagnostic actions
- [ ] Remediation approval workflow

Exit criteria:
Controlled actions are auditable and permission-checked.

## Phase 11 — Integration and Pilot
Week 12

- [ ] End-to-end tests
- [ ] Docker Compose deployment
- [ ] Documentation
- [ ] Demonstration scenarios
- [ ] Pilot user feedback

Exit criteria:
MVP is ready for controlled pilot testing.

## Roadmap Policy

Dates are targets, not automatic completion guarantees.
Each phase requires working demonstrations and tests.
